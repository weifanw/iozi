    A quick introduction
    Small engine.
    Thoughtful search.
    
    
    
      
    iozi finds keywords in a collection of text documents. Start with the sample library, or add your own .txt and .md files.
    
      
    Any word / All words
    Match at least one keyword, or require every keyword. Repeating a word does not give it extra weight.
    Results, in a useful order
    BM25 scores balance word rarity, repetition, and document length. A score is a ranking value, not a percentage or a probability.
    A precise scope
    Search recognizes English ASCII letters and numbers, ignores letter case, and splits punctuation. For example, “C++” becomes “c”. Chinese keywords, stemming, phrases, and semantic search are not supported in this version.
    Private by design
    Your file contents are read and searched locally in this browser tab. They are not uploaded or saved. Reloading the page clears your imported collection. The site makes ordinary requests to load its own code and sample files.
    Room for a small collection
    Up to 100 documents, 1 MiB per file and 10 MiB in total. Queries can be up to 4,096 UTF-8 bytes. The first import replaces the sample library; further imports add to your files.
    
      
    The same open-source C++20 engine powers the command-line tool and this browser experience through WebAssembly.
